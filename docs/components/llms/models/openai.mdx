To use OpenAI LLM models, you have to set the `OPENAI_API_KEY` environment variable. You can obtain the OpenAI API key from the [OpenAI Platform](https://platform.openai.com/account/api-keys).

> **Note**: The following are currently unsupported with reasoning models `Parallel tool calling`,`temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `logprobs`, `top_logprobs`, `logit_bias`, `max_tokens`

## Usage

<CodeGroup>
```python Python
import os
from mem0 import Memory

os.environ["OPENAI_API_KEY"] = "your-api-key"

config = {
    "llm": {
        "provider": "openai",
        "config": {
            "model": "gpt-5-mini",
            "temperature": 0.2,
            "max_tokens": 2000,
        }
    }
}

# Use Openrouter by passing it's api key
# os.environ["OPENROUTER_API_KEY"] = "your-api-key"
# config = {
#    "llm": {
#        "provider": "openai",
#        "config": {
#            "model": "meta-llama/llama-3.1-70b-instruct",
#        }
#    }
# }

m = Memory.from_config(config)
messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about thriller movies? They can be quite engaging."},
    {"role": "user", "content": "I’m not a big fan of thriller movies but I love sci-fi movies."},
    {"role": "assistant", "content": "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future."}
]
m.add(messages, user_id="alice", metadata={"category": "movies"})
```

```typescript TypeScript
import { Memory } from 'mem0ai/oss';

const config = {
  llm: {
    provider: 'openai',
    config: {
      apiKey: process.env.OPENAI_API_KEY || '',
      model: 'gpt-4-turbo-preview',
      temperature: 0.2,
      maxTokens: 1500,
    },
  },
};

const memory = new Memory(config);
const messages = [
    {"role": "user", "content": "I'm planning to watch a movie tonight. Any recommendations?"},
    {"role": "assistant", "content": "How about thriller movies? They can be quite engaging."},
    {"role": "user", "content": "I’m not a big fan of thriller movies but I love sci-fi movies."},
    {"role": "assistant", "content": "Got it! I'll avoid thriller recommendations and suggest sci-fi movies in the future."}
]
await memory.add(messages, { userId: "alice", metadata: { category: "movies" } });
```
</CodeGroup>

We also support the new [OpenAI structured-outputs](https://platform.openai.com/docs/guides/structured-outputs/introduction) model.

```python
import os
from mem0 import Memory

os.environ["OPENAI_API_KEY"] = "your-api-key"

config = {
    "llm": {
        "provider": "openai_structured",
        "config": {
            "model": "gpt-5-mini",
            "temperature": 0.0,
        }
    }
}

m = Memory.from_config(config)
```

## Config

For the Python `openai` provider, OpenAI-compatible local servers can use explicit
backend fields and bounded client behavior:

```python
llm_config = {
    "provider": "openai",
    "config": {
        "model": "gemma-4-12B-it-4bit",
        "openai_base_url": "http://127.0.0.1:8080/v1",
        "temperature": 0,
        "max_tokens": 2048,
        "extra_body": {"chat_template_kwargs": {"enable_thinking": False}},
        "request_timeout": 120,
        "max_retries": 0,
    },
}
```

`extra_body` is opt-in and passed to the OpenAI SDK; its fields must be supported
by your backend. A per-call `extra_body` replaces the configured dictionary.
Avoid conflicting standard fields such as `model` or `messages` in this dictionary.
`request_timeout` is a positive finite SDK timeout in seconds, not a total
wall-clock deadline or proof of server cancellation. The HTTPX transport applies
timeouts per connect/read/write/pool phase; the read timeout limits inactivity
between reads, so an active response can exceed that value in total elapsed time.
`max_retries` is a nonnegative integer; zero disables SDK retries. Omitting these
options preserves SDK defaults.
Use the server's key through `OPENAI_API_KEY`; do not save keys in configuration
files. Unset `OPENROUTER_API_KEY` when testing a local endpoint because it selects
the OpenRouter route. These options do not configure embeddings, other provider
clients, or the TypeScript SDK.

Structured responses requested with `response_format` or tools that end with
`finish_reason="length"` raise `LLMError`, even when the returned prefix happens
to be valid JSON. Plain-text calls still return intentionally limited text.
Memory extraction also raises `LLMError` for malformed responses rather than
treating them as a successful empty write; an explicit `{"memory": []}` remains
a valid no-facts result.

Size the output allowance for your inputs and inspect generation finish reasons.
A larger allowance alone does not fix an extractor that repeatedly emits
unchanged memories. Verify persisted facts, not just a successful HTTP response.

All available parameters for the `openai` config are present in [Master List of All Params in Config](../config).
